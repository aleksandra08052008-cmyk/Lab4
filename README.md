# Лабораторна робота №4
- Студен: Пономаренко Олександа
- Група: ІО-о51
- Номер в групі: 5

__Тема:__
Відношення між класами в мові програмування Java.

__Мета:__ 
Ознайомлення з відношеннями між класами в мові
програмування Java. Здобуття навичок у використанні
відношень між класів в мові програмування Java.

## Варіант завдання
 Створити класи для:
- літер
- слів
- речень
- тексту

Слово повинно складатися з масиву літер, речення — з масиву слів та розділових знаків, текст — з масиву речень.
Також необхідно замінити послідовність пробілів і табуляцій одним пробілом.

## Опис завдання
У даній лабораторній роботі необхідно:
- створити окремі класи для Letter, Word, Sentence, Text;
- реалізувати композицію класів (текст → речення → слова → літери);
- обробити текстові дані;
- нормалізувати пробіли та табуляції;
- реалізувати виконавчий клас;
- написати модульні тести.

## Опис реалізації
У програмі реалізовано наступні класи:

- **Letter** — представляє окрему літеру
- **Word** — складається з масиву літер
- **Sentence** — складається з масиву слів
- **Text** — складається з масиву речень

У класі "Text" виконується:
- розбиття тексту на речення;
- обробка пробілів і табуляцій;
- формування структури тексту.

## Опис тестів

__testTextCreationNotNull()__

Перевіряє, що об’єкт Text створюється коректно.

__testTextToStringNotEmpty()__

Перевіряє, що результат роботи не є порожнім рядком.

__testWhitespaceNormalization()__

Перевіряє заміну зайвих пробілів і табуляцій.


__testSentenceStructureExists()__

Перевіряє наявність структури речень.

__testWordBreakdownLogic()__

Перевіряє правильність роботи класу Word.

__testLetterInsideWord()__

Перевіряє роботу класу Letter через Word.


__Висновок__

У ході лабораторної роботи було реалізовано ієрархічну структуру тексту за допомогою класів Java.
Було створено класи для літер, слів, речень та тексту, а також реалізовано композицію об’єктів.
Додатково було виконано обробку тексту з нормалізацією пробілів та табуляцій.
